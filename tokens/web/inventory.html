Sources and privacy
Private setup

Requires Python 3.10 or newer. The app needs no account, API key or third-party Python dependency.

python3 -m tokens.inventory --demo

To use your own existing records, restart without --demo. You choose which folders to connect.

Claude Code and Codex JSONL counters are supported. Cursor counters are unsupported. This app does not install or sign in to a coding agent.

About these numbers
Rates estimate API-equivalent usage; they are not your bill. Unconfigured model rates remain unknown. Project identity and activity are independent metadata suggestions. Other work requires an explicit No product label; activity such as Admin or Agent-to-agent alone never establishes it. No prompt/reply interpretation or fractional token allocation is used. Copies, deleted logs, unsupported formats and cloud-only records limit coverage.

Use your local coding agent
The CLI starts no model and uploads nothing. If your agent uses a hosted model, anything you pass into that conversation goes to its provider. Preview the summary and explicitly approve that handoff first. Project names can still be private.
